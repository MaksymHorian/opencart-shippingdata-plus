Shipping Data Plus для OpenCart

Безкоштовне доповнення під ліцензією MIT покращує роботу з уже встановленими модулями доставки OC Max (Нова пошта, Укрпошта, Meest, Rozetka Delivery). Воно не замінює модулі перевізників і не має власних ключів API чи ліцензії: номери накладних беруться з полів замовлення, а перевірка API та оновлення міст/відділень використовує налаштування відповідного модуля доставки.

У адмін-панелі з`являються колонка Відправлення, номер і кнопка трекінгу на картці замовлення, меню швидких дій у шапці та резервні копії довідників перевізників. У кабінеті покупця — той самий номер і посилання «Відстежити на сайті перевізника» в історії замовлень.

Вкладка «Загальні»

  • Картка замовлення — номер і кнопки в рядку способу доставки (крім замовлень, якими керує Nova Poshta PRO)
  • Кабінет покупця — колонка в історії замовлень і рядок на сторінці замовлення без копіювання

  • не змінює PHP модулів Shipping Data або перевізників — лише OCMOD-патчі інтерфейсу

Інструкція (встановлення, налаштування, оновлення та видалення)

Встановлення
Перед встановленням на робочому магазині протестуйте на копії сайту!

Оберіть папку дистрибутива під вашу версію OpenCart. У OpenCart 3.X.X.X, OpenCart 2.3.X.X та OpenCart 2.0.0.0-2.2.0.0 поруч лежать три елементи: shippingdata_plus.ocmod.zip (install.xml і upload/ всередині), папка upload/ і файл shippingdata_plus.ocmod.xml. Для OpenCart 1.5.x — лише ручне копіювання (див. нижче).

OpenCart 3.x, 2.3.x, 2.0–2.2.x — основний шлях
  1. Додатки → Встановлення доповнень — завантажте shippingdata_plus.ocmod.zip з папки вашої версії.
  2. Додатки → Модифікації — натисніть «Оновити».
  3. Додатки → Модулі — знайдіть Shipping Data Plus, натисніть «Встановити», потім «Редагувати».
  4. Увімкніть модуль і потрібні поверхні; натисніть «Зберегти».
Якщо архів не встановлюється

Коли інсталятор відхиляє zip або завантаження не вдається — скопіюйте файли вручну, потім зареєструйте модифікатор:

  1. Скопіюйте вміст папки upload/ цієї версії у корінь сайту (FTP або менеджер файлів хостингу).
  2. Додатки → Встановлення доповнень — завантажте модифікатор:
    • OpenCart 2.0–2.2 і 2.3: завантажте shippingdata_plus.ocmod.xml з тієї ж папки версії (інсталятор приймає окремий файл .ocmod.xml).
    • OpenCart 3.x: інсталятор приймає лише файл із розширенням .ocmod.zip, а не «голий» XML. Після копіювання через FTP знову завантажте shippingdata_plus.ocmod.zip, щоб install.xml потрапив у базу, потім Додатки → Модифікації — «Оновити».
  3. Додатки → Модулі — встановіть Shipping Data Plus, відкрийте «Редагувати», увімкніть модуль і збережіть.
OpenCart 1.5.x

Інсталятор доповнень відсутній — встановлення вручну:

  1. Скопіюйте вміст папки upload з пакета OpenCart 1.5.X.X у корінь сайту (FTP або менеджер файлів хостингу).
  2. Скопіюйте shippingdata_plus.xml у vqmod/xml/ на сервері.
  3. У адмін-панелі: Додатки → Модулі — встановіть Shipping Data Plus, відкрийте «Редагувати», увімкніть модуль і збережіть.
Налаштування

Модифікатор shippingdata_plus (файл system/shippingdata_plus.ocmod.xml) додає:

  • колонку відправлення в списку замовлень;
  • блок номера/трекінгу на картці замовлення;
  • колонку та рядок у кабінеті покупця;
  • меню в шапці адміністратора.

Кожну поверхню можна вимкнути окремим перемикачем, якщо модуль увімкнено глобально.

Резервні копії довідників не включають таблиці накладних чи реєстрів — лише міста, відділення, області та довідники перевізника з whitelist модуля.

Оновлення
  1. Зробіть резервну копію файлів і бази даних.
  2. За бажанням збережіть резервні копії довідників на вкладці «Резервні копії».
  3. Замініть файли з нового архіву, оновіть OCMOD і кеш модифікацій.
  4. Перевірте перемикачі на вкладці «Загальні» і збережіть.
Видалення
  1. Видаліть модифікатор Shipping Data Plus і оновіть кеш модифікацій.
  2. Додатки → Модулі — «Видалити» навпроти Shipping Data Plus (видаляються shadow-таблиці __sdp / __aside і налаштування модуля).
  3. Видаліть файли модуля з сервера.

Таблиці довідників перевізників (novaposhta_*, ukrposhta_* тощо) залишаються без змін.

Підтримка (питання/відповіді, список змін, контакти)

Питання/Відповіді

  • модуль Shipping Data Plus вимкнено або вимкнено потрібну поверхню (список, картка, кабінет);
  • у замовлення немає номера в полі перевізника ({carrier}_cn_number) або спосіб доставки не сумісний з модулем перевізника;
  • не оновлено кеш модифікацій після встановлення OCMOD.

Ні. Перевірка API та оновлення міст/відділень викликають helper відповідного модуля доставки з його ключами.

Пункт Shipping Data Plus у верхньому меню поруч із «Вихід», а не іконка вантажівки. На картці замовлення номер — на вкладці адреси доставки.

Shipping Data Plus for OpenCart

A free MIT extension that enhances already installed OC Max carrier modules (Nova Poshta, Ukrposhta, Meest, Rozetka Delivery). It does not replace carrier modules and has no license key or API keys of its own: consignment numbers come from order fields; API checks and city/department refresh use each carrier module’s credentials.

In admin you get a Shipment column, TTN and tracking on the order page, a header quick menu, and spare directory backups. In the customer account — the same number and a “Track on carrier website” link.

Guide (install, configure, upgrade, remove)

Installation
Before installing on a live store, test on a copy of the site!

Pick the package folder that matches your OpenCart version. In OpenCart 3.X.X.X, OpenCart 2.3.X.X, and OpenCart 2.0.0.0-2.2.0.0 you will find three items: shippingdata_plus.ocmod.zip (install.xml and upload/ inside), the upload/ folder, and shippingdata_plus.ocmod.xml. OpenCart 1.5.x uses manual file copy only (see below).

OpenCart 3.x, 2.3.x, 2.0 through 2.2.x — primary path
  1. Extensions → Installer — upload shippingdata_plus.ocmod.zip from your version folder.
  2. Extensions → Modifications — click Refresh.
  3. Extensions → Modules — find Shipping Data Plus, click Install, then Edit.
  4. Enable the module and the surfaces you need; Save.
If the zip does not install

When the installer rejects the archive or upload fails, deploy files manually, then register the modifier:

  1. Copy the contents of that version’s upload/ folder to the shop root (FTP or hosting file manager).
  2. Extensions → Installer — load the modifier:
    • OpenCart 2.0–2.2 and 2.3: upload shippingdata_plus.ocmod.xml from the same version folder (the installer accepts a bare .ocmod.xml file).
    • OpenCart 3.x: the installer accepts only a file whose name ends in .ocmod.zip, not a bare XML file. After the FTP copy, upload shippingdata_plus.ocmod.zip again so install.xml is registered, then Extensions → Modifications — Refresh.
  3. Extensions → Modules — install Shipping Data Plus, open Edit, enable the module, and Save.
OpenCart 1.5.x

There is no extension installer. Install manually:

  1. Copy the contents of the upload folder from the OpenCart 1.5.X.X package to the shop root (FTP or hosting file manager).
  2. Copy shippingdata_plus.xml into vqmod/xml/ on the server.
  3. In admin: Extensions → Modules — install Shipping Data Plus, open Edit, enable the module, and Save.
Configuration

Modifier shippingdata_plus.ocmod.xml hooks order list, order info, customer account templates, and admin header. Each surface can be toggled independently.

Upgrade
  1. Backup files and database.
  2. Replace module files; refresh OCMOD cache.
  3. Review General tab switches and Save.
Uninstall
  1. Remove the modifier and refresh the cache.
  2. Uninstall the module under Extensions → Modules.
  3. Delete module files from the server.

Инструкция

Установка
Перед установкой на рабочем магазине протестируйте на копии сайта!

Выберите папку дистрибутива под вашу версию OpenCart. В OpenCart 3.X.X.X, OpenCart 2.3.X.X и OpenCart 2.0.0.0-2.2.0.0 рядом лежат три элемента: shippingdata_plus.ocmod.zip (install.xml и upload/ внутри), папка upload/ и файл shippingdata_plus.ocmod.xml. Для OpenCart 1.5.x — только ручное копирование (см. ниже).

OpenCart 3.x, 2.3.x, 2.0–2.2.x — основной путь
  1. Дополнения → Установка — загрузите shippingdata_plus.ocmod.zip из папки вашей версии.
  2. Дополнения → Модификации — нажмите «Обновить».
  3. Дополнения → Модули — найдите Shipping Data Plus, нажмите «Установить», затем «Редактировать».
  4. Включите модуль и нужные поверхности; сохраните.
Если архив не устанавливается

Когда установщик отклоняет zip или загрузка не удаётся — скопируйте файлы вручную, затем зарегистрируйте модификатор:

  1. Скопируйте содержимое папки upload/ этой версии в корень сайта (FTP или файловый менеджер хостинга).
  2. Дополнения → Установка — загрузите модификатор:
    • OpenCart 2.0–2.2 и 2.3: загрузите shippingdata_plus.ocmod.xml из той же папки версии (установщик принимает отдельный файл .ocmod.xml).
    • OpenCart 3.x: установщик принимает только файл с расширением .ocmod.zip, а не «голый» XML. После копирования по FTP снова загрузите shippingdata_plus.ocmod.zip, чтобы install.xml попал в базу, затем Дополнения → Модификации — «Обновить».
  3. Дополнения → Модули — установите Shipping Data Plus, откройте «Редактировать», включите модуль и сохраните.
OpenCart 1.5.x

Установщика дополнений нет — установка вручную:

  1. Скопируйте содержимое папки upload из пакета OpenCart 1.5.X.X в корень сайта (FTP или файловый менеджер хостинга).
  2. Скопируйте shippingdata_plus.xml в vqmod/xml/ на сервере.
  3. В админ-панели: Дополнения → Модули — установите Shipping Data Plus, откройте «Редактировать», включите модуль и сохраните.
Настройка

Модификатор shippingdata_plus.ocmod.xml добавляет колонку, блок на карточке заказа, кабинет покупателя и меню в шапке. Каждую поверхность можно отключить отдельно.

Обновление
  1. Резервная копия файлов и БД.
  2. Замена файлов, обновление OCMOD.
  3. Проверка переключателей и сохранение.
Удаление
  1. Удалить модификатор и обновить кеш.
  2. Удалить модуль в списке модулей.
  3. Удалить файлы с сервера.
