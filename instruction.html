Shipping Data Plus для OpenCart

Це доповнення для магазинів, які вже використовують модулі доставки OC Max і не планують оновлювати їх найближчим часом або не можуть оновити їх з технічних причин. Той самий функціонал з’явиться в майбутніх оновленнях цих модулів доставки. Доповнення працює разом із такими модулями:

  • Nova Poshta API
  • Ukrposhta API
  • Meest
  • Rozetka Delivery

Доповнення сумісне з модулем Nova Poshta PRO.

Доповнення не замінює ці модулі. Номери накладних беруться з полів замовлення, які модулі перевізників уже зберігають. Перевірка API та оновлення міст і відділень використовує налаштування відповідного модуля доставки.

Опис (основна інформація)

Функціональні можливості
  • показ номера відправлення (ТТН) у списку замовлень адмін-панелі, на картці замовлення та в кабінеті покупця
  • кнопка переходу на офіційний трекінг перевізника
  • копіювання номеру ТТН у списку замовлень та на картці замовлення
  • меню у верхній навігаційній панелі адмін-панелі: перевірка API, оновлення міст і відділень для увімкнених перевізників
  • окремі перемикачі для кожного розділу: статус модуля, меню у верхній навігаційній панелі, список замовлень, картка замовлення, кабінет покупця
  • одна резервна копія довідників кожного перевізника з можливістю відновлення
  • якщо увімкнено модуль Nova Poshta PRO і його колонка в списку замовлень уже заповнена, модуль доповнює лише порожні комірки; на картці замовлення номер не показується для замовлень, якими керує Nova Poshta PRO
Підтримувані мови
  • українська
  • англійська
  • російська

Інтерфейс модуля перекладено для адмін-панелі та кабінету покупця. Назви перевізників беруться з модулів доставки.

Сумісність
  • OpenCart v. 1.5.Х.Х, 2.X.X.Х, 3.Х.Х.Х (а також збірки на базі OpenCart відповідних версій)
  • потрібен хоча б один увімкнений модуль доставки OC Max: Nova Poshta API, Ukrposhta API, Meest або Rozetka Delivery
  • не змінює PHP модулів Shipping Data або перевізників — лише OCMOD-патчі інтерфейсу
Вимоги
  • PHP 7.2+ (рекомендовано для OpenCart 3.x)
  • встановлений і налаштований модуль доставки перевізника

Інструкція (встановлення, налаштування, оновлення та видалення)

Встановлення
Перед встановленням на робочому магазині протестуйте на копії сайту!

Оберіть папку дистрибутива під вашу версію OpenCart. У OpenCart 3.X.X.X, OpenCart 2.3.X.X та OpenCart 2.0.0.0-2.2.0.0 лежать shippingdata_plus.ocmod.zip (install.xml і upload/ всередині) і папка upload/. Модифікатор — у теці modification/: для OpenCart 3 це shippingdata_plus.ocmod.zip, для 2.x — файл shippingdata_plus.ocmod.xml. Для OpenCart 1.5.x — лише ручне копіювання (див. нижче).

OpenCart 3.x, 2.3.x, 2.0–2.2.x — основний шлях
  1. Додатки → Встановлення доповнень — завантажте shippingdata_plus.ocmod.zip з папки вашої версії.
  2. Додатки → Модифікації — натисніть «Оновити».
  3. Додатки → Модулі — знайдіть Shipping Data Plus, натисніть «Встановити», потім «Редагувати».
  4. Увімкніть модуль і потрібні розділи; натисніть «Зберегти», щоб зберегти налаштування.
Якщо архів не встановлюється

Коли інсталятор відхиляє zip або завантаження не вдається — скопіюйте файли вручну, потім зареєструйте модифікатор:

  1. Скопіюйте вміст папки upload/ цієї версії у корінь сайту (FTP або менеджер файлів хостингу).
  2. Додатки → Встановлення доповнень — завантажте модифікатор:
    • OpenCart 2.0–2.2 і 2.3: завантажте modification/shippingdata_plus.ocmod.xml (інсталятор приймає окремий файл .ocmod.xml).
    • OpenCart 3.x: інсталятор приймає лише .ocmod.zip. Завантажте modification/shippingdata_plus.ocmod.zip. Потім Додатки → Модифікації — «Оновити».
  3. Додатки → Модулі — встановіть Shipping Data Plus, відкрийте «Редагувати», увімкніть модуль і збережіть налаштування («Зберегти»).
OpenCart 1.5.x

Інсталятор доповнень відсутній — встановлення вручну:

  1. Скопіюйте вміст папки upload з пакета OpenCart 1.5.X.X у корінь сайту (FTP або менеджер файлів хостингу).
  2. Скопіюйте modification/shippingdata_plus.xml у vqmod/xml/ на сервері.
  3. У адмін-панелі: Додатки → Модулі — встановіть Shipping Data Plus, відкрийте «Редагувати», увімкніть модуль і збережіть налаштування («Зберегти»).
Налаштування

Модифікатор shippingdata_plus додає:

  • колонку відправлення в списку замовлень;
  • блок номера/трекінгу на картці замовлення;
  • колонку та рядок у кабінеті покупця;
  • меню в верхній навігаційній панелі адміністратора.

Кожен розділ можна вимкнути окремим перемикачем, якщо модуль увімкнено глобально.

Резервні копії довідників не включають таблиці накладних чи реєстрів — лише міста, відділення, області та довідники перевізника з whitelist модуля.

Оновлення
  1. Зробіть резервну копію файлів і бази даних.
  2. За бажанням збережіть резервні копії довідників на вкладці «Резервні копії».
  3. Замініть файли з нового архіву, оновіть OCMOD і кеш модифікацій.
  4. Перевірте перемикачі на вкладці «Загальні» і збережіть налаштування.
Видалення
  1. Видаліть модифікатор Shipping Data Plus і оновіть кеш модифікацій.
  2. Додатки → Модулі — «Видалити» навпроти Shipping Data Plus.
  3. Видаліть файли модуля з сервера.

Таблиці довідників перевізників (novaposhta_*, ukrposhta_* тощо) залишаються без змін.

Підтримка (питання/відповіді, список змін, контакти)

Питання/Відповіді

  • модуль Shipping Data Plus вимкнено або вимкнено потрібний розділ (список, картка, кабінет);
  • у замовлення немає номера в полі перевізника ({carrier}_cn_number) або спосіб доставки не сумісний з модулем перевізника;
  • не оновлено кеш модифікацій після встановлення OCMOD.

Ні. Перевірка API та оновлення міст/відділень викликають helper відповідного модуля доставки з його ключами.

Пункт Shipping Data Plus у верхньому меню поруч із «Вихід», а не іконка вантажівки. На картці замовлення номер — на вкладці адреси доставки.

Shipping Data Plus for OpenCart

This add-on is for shops that already use OC Max delivery modules and do not plan to update them soon, or cannot update them for technical reasons. The same functionality will be added in future updates of those delivery modules. The extension works with these modules:

  • Nova Poshta API
  • Ukrposhta API
  • Meest
  • Rozetka Delivery

The extension is compatible with the Nova Poshta PRO module.

It does not replace those modules. Waybill numbers come from the order fields the carrier modules already store. API check and city/department refresh use each carrier module’s own settings.

Description (overview)

Features
  • consignment number (TTN) in the admin panel order list, on the order page, and in the customer account
  • tracking button to the carrier’s public tracker
  • copy of the TTN number in the order list and on the order page
  • menu in the upper admin navigation panel: API check, city and department refresh for enabled carriers
  • per-section toggles: module status, menu in the upper admin navigation panel, order list, order page, customer account
  • one directory backup per carrier with restore
  • when the Nova Poshta PRO module is enabled and its order-list column is already filled, this module only fills empty cells; TTN is not shown on the order page for orders managed by Nova Poshta PRO
Languages
  • Ukrainian
  • English
  • Russian
Compatibility
  • OpenCart v. 1.5.x.x, 2.x.x.x, 3.x.x.x (as well as OpenCart-based builds of corresponding versions)
  • requires at least one enabled OC Max delivery module: Nova Poshta API, Ukrposhta API, Meest, or Rozetka Delivery
  • UI-only OCMOD — does not patch carrier PHP
Requirements
  • PHP 7.2+ recommended for OpenCart 3.x
  • installed and configured carrier delivery module

Guide (install, configure, upgrade, remove)

Installation
Before installing on a live store, test on a copy of the site!

Pick the package folder that matches your OpenCart version. In OpenCart 3.X.X.X, OpenCart 2.3.X.X, and OpenCart 2.0.0.0-2.2.0.0 you will find shippingdata_plus.ocmod.zip (install.xml and upload/ inside) and the upload/ folder. The modifier is in modification/: OpenCart 3 uses shippingdata_plus.ocmod.zip; 2.x uses shippingdata_plus.ocmod.xml. OpenCart 1.5.x uses manual file copy only (see below).

OpenCart 3.x, 2.3.x, 2.0 through 2.2.x — primary path
  1. Extensions → Installer — upload shippingdata_plus.ocmod.zip from your version folder.
  2. Extensions → Modifications — click Refresh.
  3. Extensions → Modules — find Shipping Data Plus, click Install, then Edit.
  4. Enable the module and the sections you need; click Save to save the settings.
If the zip does not install

When the installer rejects the archive or upload fails, deploy files manually, then register the modifier:

  1. Copy the contents of that version’s upload/ folder to the shop root (FTP or hosting file manager).
  2. Extensions → Installer — load the modifier:
    • OpenCart 2.0–2.2 and 2.3: upload modification/shippingdata_plus.ocmod.xml (the installer accepts a bare .ocmod.xml file).
    • OpenCart 3.x: the installer accepts only .ocmod.zip. Upload modification/shippingdata_plus.ocmod.zip. Then Extensions → Modifications — Refresh.
  3. Extensions → Modules — install Shipping Data Plus, open Edit, enable the module, and save the settings (Save).
OpenCart 1.5.x

There is no extension installer. Install manually:

  1. Copy the contents of the upload folder from the OpenCart 1.5.X.X package to the shop root (FTP or hosting file manager).
  2. Copy modification/shippingdata_plus.xml into vqmod/xml/ on the server.
  3. In the admin panel: Extensions → Modules — install Shipping Data Plus, open Edit, enable the module, and save the settings (Save).
Configuration

Modifier shippingdata_plus adds hooks for the order list, order info, customer account templates, and the upper admin navigation panel menu. Each section can be toggled independently.

Upgrade
  1. Backup files and database.
  2. Replace module files; refresh OCMOD cache.
  3. Review the switches on the General tab and save the settings.
Uninstall
  1. Remove the modifier and refresh the cache.
  2. Uninstall the module under Extensions → Modules.
  3. Delete module files from the server.

Support

Shipping Data Plus для OpenCart

Это дополнение для магазинов, которые уже используют модули доставки OC Max и не планируют обновлять их в ближайшее время или не могут обновить их по техническим причинам. Тот же функционал появится в будущих обновлениях этих модулей доставки. Дополнение работает вместе с такими модулями:

  • Nova Poshta API
  • Ukrposhta API
  • Meest
  • Rozetka Delivery

Дополнение совместимо с модулем Nova Poshta PRO.

Дополнение не заменяет эти модули. Номера накладных берутся из полей заказа, которые модули перевозчиков уже сохраняют. Проверка API и обновление городов и отделений используют настройки соответствующего модуля доставки.

Описание (основное)

Функциональные возможности
  • номер отправления (ТТН) в списке заказов админ-панели, на карточке заказа и в кабинете покупателя
  • кнопка перехода на официальный трекинг перевозчика
  • копирование номера ТТН в списке заказов и на карточке заказа
  • меню в верхней навигационной панели админ-панели: проверка API, обновление городов и отделений для включённых перевозчиков
  • отдельные переключатели для каждого раздела: статус модуля, меню в верхней навигационной панели, список заказов, карточка заказа, кабинет покупателя
  • одна резервная копия справочников каждого перевозчика с восстановлением
  • если включён модуль Nova Poshta PRO и его колонка в списке заказов уже заполнена, модуль дополняет только пустые ячейки; на карточке заказа номер не показывается для заказов, которыми управляет Nova Poshta PRO
Поддерживаемые языки
  • украинский
  • английский
  • русский
Совместимость
  • OpenCart v. 1.5.x.x, 2.x.x.x, 3.x.x.x (а также сборки на базе OpenCart соответствующих версий)
  • нужен хотя бы один включённый модуль доставки OC Max: Nova Poshta API, Ukrposhta API, Meest или Rozetka Delivery
Требования
  • PHP 7.2+ (рекомендуется для OpenCart 3.x)
  • установленный и настроенный модуль доставки перевозчика

Инструкция

Установка
Перед установкой на рабочем магазине протестируйте на копии сайта!

Выберите папку дистрибутива под вашу версию OpenCart. В OpenCart 3.X.X.X, OpenCart 2.3.X.X и OpenCart 2.0.0.0-2.2.0.0 лежат shippingdata_plus.ocmod.zip (install.xml и upload/ внутри) и папка upload/. Модификатор — в папке modification/: для OpenCart 3 это shippingdata_plus.ocmod.zip, для 2.x — файл shippingdata_plus.ocmod.xml. Для OpenCart 1.5.x — только ручное копирование (см. ниже).

OpenCart 3.x, 2.3.x, 2.0–2.2.x — основной путь
  1. Дополнения → Установка — загрузите shippingdata_plus.ocmod.zip из папки вашей версии.
  2. Дополнения → Модификации — нажмите «Обновить».
  3. Дополнения → Модули — найдите Shipping Data Plus, нажмите «Установить», затем «Редактировать».
  4. Включите модуль и нужные разделы; нажмите «Сохранить», чтобы сохранить настройки.
Если архив не устанавливается

Когда установщик отклоняет zip или загрузка не удаётся — скопируйте файлы вручную, затем зарегистрируйте модификатор:

  1. Скопируйте содержимое папки upload/ этой версии в корень сайта (FTP или файловый менеджер хостинга).
  2. Дополнения → Установка — загрузите модификатор:
    • OpenCart 2.0–2.2 и 2.3: загрузите modification/shippingdata_plus.ocmod.xml (установщик принимает отдельный файл .ocmod.xml).
    • OpenCart 3.x: установщик принимает только .ocmod.zip. Загрузите modification/shippingdata_plus.ocmod.zip. Затем Дополнения → Модификации — «Обновить».
  3. Дополнения → Модули — установите Shipping Data Plus, откройте «Редактировать», включите модуль и сохраните настройки («Сохранить»).
OpenCart 1.5.x

Установщика дополнений нет — установка вручную:

  1. Скопируйте содержимое папки upload из пакета OpenCart 1.5.X.X в корень сайта (FTP или файловый менеджер хостинга).
  2. Скопируйте modification/shippingdata_plus.xml в vqmod/xml/ на сервере.
  3. В админ-панели: Дополнения → Модули — установите Shipping Data Plus, откройте «Редактировать», включите модуль и сохраните настройки («Сохранить»).
Настройка

Модификатор shippingdata_plus добавляет колонку в списке заказов, блок на карточке заказа, кабинет покупателя и меню в верхней навигационной панели администратора. Каждый раздел можно отключить отдельно.

Обновление
  1. Резервная копия файлов и БД.
  2. Замена файлов, обновление OCMOD.
  3. Проверьте переключатели на вкладке «Общие» и сохраните настройки.
Удаление
  1. Удалить модификатор и обновить кеш.
  2. Удалить модуль в списке модулей.
  3. Удалить файлы с сервера.
