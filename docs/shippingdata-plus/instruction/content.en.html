Shipping Data Plus for OpenCart

A free MIT extension that enhances already installed OC Max carrier modules (Nova Poshta, Ukrposhta, Meest, Rozetka Delivery). It does not replace carrier modules and has no license key or API keys of its own: consignment numbers come from order fields; API checks and city/department refresh use each carrier module’s credentials.

In admin you get a Shipment column, TTN and tracking on the order page, a header quick menu, and spare directory backups. In the customer account — the same number and a “Track on carrier website” link.

Description (overview)

Features
Highlights
  • consignment number in order list, order info, and customer account
  • branded tracking button to the carrier’s public tracker
  • copy raw number in admin list and order info
  • admin header menu: API ping, cities and departments refresh for enabled carriers
  • one spare backup set per carrier with restore
more...
General tab
  • Status — enable the module
  • Header menu — truck icon (OC 2.x/3.x) or “Shipping Data Plus” text item (1.5.x)
  • Order list — Shipment column; fills empty Nova Poshta PRO cells when PRO is active
  • Order info — inline TTN unless Nova Poshta PRO owns that order
  • Customer account — list column and order info row (no copy button)
Backups tab
  • per-carrier regions, cities, departments, references
  • Save backup — shadow tables __sdp
  • Restore — swap live directories from spare copy

Guide (install, configure, upgrade, remove)

Installation
  1. Upload the upload folder to the shop root.
  2. Install OCMOD shippingdata_plus.ocmod.xml and refresh modifications.
  3. Extensions → Modules → install Shipping Data Plus, then Edit.
  4. Enable the module and surfaces you need; Save.
Configuration

Modifier shippingdata_plus.ocmod.xml hooks order list, order info, customer account templates, and admin header. Each surface can be toggled independently.

Upgrade
  1. Backup files and database.
  2. Replace module files; refresh OCMOD cache.
  3. Review General tab switches and Save.
Uninstall
  1. Remove the modifier and refresh the cache.
  2. Uninstall the module under Extensions → Modules.
  3. Delete module files from the server.
