Shipping Data Plus для OpenCart

Бесплатное дополнение под лицензией MIT для уже установленных модулей доставки OC Max (Новая почта, Укрпошта, Meest, Rozetka Delivery). Не заменяет модули перевозчиков и не требует собственных ключей API или лицензии OC Max: номера накладных берутся из полей заказа, проверка API и обновление городов/отделений используют настройки модуля перевозчика.

В админке — колонка Отправление, номер и трекинг на карточке заказа, меню в шапке и резервные копии справочников. В кабинете покупателя — тот же номер и ссылка отслеживания на сайте перевозчика.

Инструкция

Установка
  1. Загрузите папку upload в корень сайта.
  2. Установите OCMOD и обновите модификации.
  3. Дополнения → Модули → установите Shipping Data Plus, включите и сохраните.
Настройка

Модификатор shippingdata_plus.ocmod.xml добавляет колонку, блок на карточке заказа, кабинет покупателя и меню в шапке. Каждую поверхность можно отключить отдельно.

Обновление
  1. Резервная копия файлов и БД.
  2. Замена файлов, обновление OCMOD.
  3. Проверка переключателей и сохранение.
Удаление
  1. Удалить модификатор и обновить кеш.
  2. Удалить модуль в списке модулей.
  3. Удалить файлы с сервера.
